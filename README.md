## 💖 Tentang

Museum digital interaktif: linimasa bab per bab, peta situs warisan, brankas arsip, studio aksara & nubuat, plus kuis kurator. Dibangun sebagai SPA Vite vanilla JS agar mudah di-host statis.

## 🛠 Instalasi

```bash
git clone https://github.com/drnovia/Kediri-Cinematic-History.git
cd kediri-cinematic-history
npm install
```

## 🚀 Pemakaian

| Perintah | Fungsi |
| --- | --- |
| `npm run dev` | Dev server Vite |
| `npm run build` | Bundle produksi ke `dist/` |
| `npm run preview` | Pratinjau build lokal |

Panduan singkat: [`docs/quickstart.md`](docs/quickstart.md).

## 📁 Struktur

- `src/components/` — modul pengalaman (peta, kuis, galeri)
- `src/data/` — konten & terjemahan
- `src/core/` — state, audio, utilitas
- `tests/` — ruang tes (siap diisi)

Detail: [`docs/folder-map.md`](docs/folder-map.md).
