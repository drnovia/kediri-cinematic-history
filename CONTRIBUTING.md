# Contributing — Kediri Cinematic History

## Setup

```bash
npm install
npm run dev
```

## Guidelines

- Follow [`docs/folder-map.md`](docs/folder-map.md) when adding modules.
- Keep copy in `src/data/` separated from presentation in `src/components/`.
- Prefer accessible labels (`aria-*`, skip links) when touching `index.html` or components.
- Run `npm run build` before opening a PR.

## Pull requests

- One feature or fix per PR
- Screenshots or short screen recording for UI changes
- Credit sources for new historic content
